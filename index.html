🏙️ OpenEgregoria — how to play

Fusion: OpenCity grid zoning (RCI · power · terrain) + Egregoria agent life (citizens commute, work, shop; trucks haul freight) + IsoCity isometric camera & touch-friendly controls.

Build order

  1. Lay roads 🛣️ in a network.
  2. Build wind 🌬️ or solar ☀️ (clean, no pollution) + wires ⚡ along roads.
  3. Paint R / C / I / Office / Farm zones next to roads (avenues boost nearby growth).
  4. Buildings sprout when demand (bottom bars) is green, powered & road-adjacent.
  5. Run a road 🛣️ to the map edge to link a neighbouring town 🔗 — each link pays $8/day in trade.
  6. Sculpt wild land with ⛰️ raise / 🕳️ lower ($15/tile) — dig lakes, reclaim shores, terrace hills.
  7. Add parks 🌳, plazas ⛲, schools 🏫, clinics 🏥 and police 🚔 (all powered) near homes; a monument 🏛️ past 400 citizens; keep industry 🏭 far.
