SMW AI — how it works

  • Sees the entire game frame (js/perception.js): the full 256×224 core framebuffer, never cropped. Self-identifies the avatar by input contingency (moves-iff-commanded — patrollers score ~0), not color; threats need motion confirmation (color alone = caution-1, never panic), apples demote to decor, oversized merged blobs split instead of deleting Mario. Spots the key, keyhole, goal gate, walls (incl. ground-anchored fence/pipe detection), tall climb-walls, ceilings, pit gaps (with width and edge distance), drop-down shafts, message boxes, pipes, mushrooms and stomp popups.
  • Hears the game (js/audio.js): taps the emulator's Web Audio graph (parallel analyser, sound untouched) for level/bass/mid/high + onsets. Coin jingle (+0.6), jump blip (+0.05) and death sting (−1.0, confirms vision's death cause) become Q-features and rewards. Press Enable hearing once (browsers gate audio on a click).
  • Learns every run + reuses previous knowledge (js/learning.js): each decision does a TD update; every 25 steps + every death/exit + tab-close saves. Reloading starts run #N with all weights, danger maps, exits, best-progress and run history intact (v1/v2 brains auto-migrate). HUD shows run #N (this run x steps) · M runs total as proof.
  • Learns from deaths — tries something different: each death records level + world-X + cause AND blames the last 10 actions (decaying) with hard TD updates plus a failure taboo (−1.2/action/repeat) so the same fatal move loses next time. Death spots form a per-level danger map; a level-build map remembers every visited segment's walls/pits/enemies to warn before re-entry.
  • Uses every gameplay button: 24 actions = d-pad (left/right/up-climb/down-duck-drop) × dash (Y+X) × jump (B normal / A spin). The button lab row shows measured avg →/death per button combo — what each button does, learned from experience. (L/R only scroll the camera in SMW; Start/Select pause — menus own those.)
  • Hunts exits: goal gates count as normal exits; key-then-keyhole-then-transition counts as a secret exit. Per-level exit checklist + totals in the status panel; the brain auto-saves to localStorage and reloads on boot.
  • Reads words (js/text.js): an 8×8 OCR reader (blob-segmented, translation-tolerant, confidence-gated) reads HUD text, banners (MARIO A EMPTY, PLAYER GAME verified live at 0.8–0.95), signs and message boxes. GAME OVER counts a death, COURSE CLEAR credits the exit, EXIT/GOAL/HOUSE/KEY words steer the brain. Stylized logos aren't font text and won't read — that's stated, not hidden.
  • Reflexes: vision straight to commands: confirmed close threat → jump (spin vs spiny/piranha), pit edge near → running jump at the edge, threat below while airborne → steer onto it (stomp), key/goal/shroom/coin/pipe in sight → steer to it, enter pipes with DOWN when stalled. Every reflex shows as [REFLEX-DODGE] etc. in the HUD and learns honestly through the forced-action path. Overworld maps get their own driver (walk nodes, tap B to enter) instead of platforming reflexes. Wedged-in-doorway states escalate UP-hold → B-taps → level restart (memory kept). Pipes and mushroom power-ups (no longer mistaken for spinies) are detected explicitly.
  • Any game, not just Mario: the avatar is whoever moves iff commanded (contingency lock, via self SELF✓) — patrolling enemies score ~0 and are rejected; menu cursors can never birth tracks and claims freeze stale instead of impersonating. Camera behavior re-classifies genre at runtime (header guesses, scrolling proves, votes decay so menus can't deadlock it), re-aiming rewards and prior; each cartridge earns its own learned control map in the HUD. Mario is the main test, but the loop is cartridge-blind by design.
  • Watches you play: leave a pad on Human with AI watches and learns while you play checked and the brain records your inputs as its training actions (demonstration learning) — same rewards, deaths, danger spots and exits as when it drives. Switch that pad to AI later and it plays with what it learned from you.
  • Roots in aleju/mario-ai (MIT): same ε-greedy 0.8→0.1 schedule, same reward spirit, same raw-pixels-only rule. The Torch DQN + lsnes + CUDA stack can't run in a browser (see js/mario-ai.js).
