NHL Legacy Recomp — WASM Port

Starting a browser port of the native PC port of NHL Legacy (Xbox 360), statically recompiled via the ReXGlue SDK. Upstream: puckhead73/nhl-legacy-recomp. This page is the deployed static build of the port scaffold.
